# 方法论（METHODOLOGY）

## 1. 这本书在做什么

用六个提问（看见、记住、跟上、选择、讲述、临界）组织一部心理学流派史。它不问“谁对谁错”，问“谁在哪里划线、把什么划到外面、最后由谁付账”。

六核来自同一作者的系列专著（《区分的语法》《遗忘的边界》《错位的时间》《选择的代价》《诠释的权衡》《涌现的临界》）。本书是这套提问方式在心理学史上的应用，不新增临床或实证结论。

## 2. 每一章的记账格式

1. **一个人物/争议开场**：不讲定义，先讲发生了什么。
2. **一个核心主提问**：只用一个核心，其他作背景。
3. **它让出了什么**：一句能落到可查证历史后果的话。
4. **被埋没与回归**：这条线后来被谁、用什么语言重新捡起。
5. **一句话带走**。

格式固定，观点不固定：格式用来把不同流派放在同一张桌子上；观点用来避免把历史削成六个格子。

## 3. 证据纪律

- **A**：可查证的文献事实、可复算的结果、官方标准文本。
- **B**：稳定的公开估计或有论证的判断，但依赖样本、定义或未证前提。
- **C**：稀疏、构造性或思辨的解释，只作方向判断。
- **结论强度不超过证据强度。**C 级只作方向判断，绝不伪装成 A 级。

第三层还区分：底线主张（即使本章大半被推翻仍成立）、条件主张（在明确前提下成立）、思辨延伸（留给未来）。

## 4. “让出”的三条判据

1. **载体判据**：有没有新的工具/方法/制度能接住原来的问题？
2. **翻译判据**：回来的部分能不能被独立检验？
3. **损失判据**：翻译丢掉了什么？如果丢掉的是原概念最核心的东西，那“回归”就只是借用一个名字。

三条都通过，才是一次真正的回归。只通过第一条，是“借尸还魂”；只通过第二条，是“简化”；只通过第三条，是“考古”。

## 5. 可证伪登记簿

附录 F 把本书的二十条主张写成可证伪形式：每条给出“什么结果会推翻它”“怎么查”“现在是什么状态”。登记簿是 append-only：新增条目只追加，不改旧行。

## 6. 本书自己的让出

- 让出了临床细节：真实治疗是两个人的事，本书只能给框架。
- 让出了非西方传统：只零星提到，未系统处理。
- 让出了定量证据：没有系统元分析，只是“读法”。
- 让出了制度史：战争、移民、经费、学会政治，只在必要处提及。

这四条不是谦虚，是账。附录 G 把它们逐条列出。
