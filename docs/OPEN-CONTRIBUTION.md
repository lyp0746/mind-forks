# 欢迎补充（OPEN-CONTRIBUTION）

这本书是一个开放的解释框架，不是一部封闭的定论。以下四类补充尤其欢迎：

## 1. 事实更正

- 年份、人物、著作、实验细节有误。
- 某章的“让出”与同期文献不符（书里说“它让出了 X”，但当时的批评并不是 X）。
- 某位人物/流派的描述过于简化，或漏掉了关键的反例。

请附上可查证的出处（原始文献、史学著作、档案），并指出对应章/节。

## 2. 被漏掉的流派

本书主线是欧美学院心理学，明确漏掉了很多传统（见附录 G）。欢迎补充：

- 非西方传统：佛教心理学、瑜伽、儒家心性、非洲 Ubuntu、拉美解放心理学、日本森田/内观。
- 被边缘化的传统：女性主义心理学、批判心理学、去殖民心理学、残障研究、酷儿心理学。
- 中国心理学的地方史、机构史、人物史。

## 3. 反例

本书最需要的，是“让六核失效”的反例：

- 一个流派，找不到任何可查证的“让出”后果。
- 一个流派，同时保住了 C、A、T 三项。
- 一个“回归”案例，原概念与新概念完全等价（没有翻译损失）。

如果找到，请直接对照附录 F 的 F1—F4 提交。

## 4. 教学与临床反馈

- 用这本书上过课、带过读书会：哪一章最难讲？哪个练习最有效？
- 临床工作者：哪一章的“让出”分析与你的经验不符？哪一段可能误导来访者？
