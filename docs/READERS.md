# 读者说明（READERS）

## 四种读者，四条路线

书里准备了四种高度的装置：

| 装置 | 给谁 | 里面是什么 |
|---|---|---|
| 正文 | 所有人 | 人物、争议、实验、诊断；不要求心理学基础 |
| 多想一层 | 学生 | 一个概念的精确定义，或一个机制的简化模型 |
| 再想一层 | 从业者与成年人 | 这条结论有多硬、能做什么、不能做什么 |
| 给专家的注 | 研究者 | 精确陈述、文献分歧、证据等级、如何反驳 |
| 动手试试 | 全年龄 | 五分钟能做完的小观察 |

## 四条路线

- **第一次接触心理学**：只读正文与“一句话带走”。读完应能说出：精神分析、行为主义、认知、人本、系统这几路，各自最在意什么、最容易忽略什么。
- **学生**：正文 + “多想一层”；重点看每章“它让出了什么”。
- **从业者**：正文 + “再想一层”；特别注意“讲述”与“临界”两部分。
- **研究者**：直接读“给专家的注”与附录 A、E、F、P、Q。

## 最短路径

如果时间很少：读**导论**、**第 5 章**（弗洛伊德）、**第 12 章**（行为主义）、**第 24 章**（诊断政治）、**第 25 章**（回望）。五块合起来就是全书骨架。

## 三种用法

1. **通读**：按六部分顺序读，每部分约 3—5 章。
2. **查读**：用附录 A 的对照表或附录 H.8 的主题索引，查一个流派/概念。
3. **教学**：附录 H.11 是十二周大纲，H.13 是九十分钟讲座大纲，H.12 是十个讨论题。

## 一个约定

书中凡出现 **A／B／C**，是在说这条结论有多硬：A 可查证/可复算；B 有论证但依赖样本、定义或未证前提；C 只是猜想/方向判断。**结论强度不超过证据强度。**
