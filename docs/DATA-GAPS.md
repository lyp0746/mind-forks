# 数据缺口（DATA-GAPS）

本书是“账本史”，不是“证据手册”。它引用了历史事实、少量效应量与复现率，但没有做系统元分析。以下是明确缺口，读者应知道本书在哪里停止。

| 缺口 | 为什么缺 | 对结论的影响 | 获取路径 |
|---|---|---|---|
| 临床疗效的系统证据 | 本书不裁判疗效，只引用个别指南与元分析 | 不能从本书得出“哪种疗法更好” | Cochrane、NICE、APA 指南、各疗法元分析 |
| 效应量的系统汇总 | 只举了复现率与 CBT 效应量等例子 | “效应大小”的判断是示意 | 各领域元分析、OSC 报告 |
| 非西方心理学传统 | 作者知识边界；以欧美主线为主 | 佛教、瑜伽、儒家、Ubuntu、解放心理学被压缩 | 文化心理学、本土心理学、区域心理学史 |
| 中国心理学的完整脉络 | 只在少数章与附录 L 提及 | 制度史、翻译史、学科史被省略 | 中国心理学史专著、学会史料、口述史 |
| 性别、性与残障 | 本书未系统处理 | “正常/异常”的划线里，这是最重要的维度之一 | 女性主义心理学、残障研究、酷儿理论 |
| 阶级、殖民与全球南方 | 未做系统的政治经济学分析 | “谁付账”停在个人与家庭 | 批判心理学、去殖民心理学、全球心理健康 |
| 制度史 | 战争、移民、经费、学会、出版社、保险 | 很多“理论胜负”其实是制度胜负 | 学科史、科学社会学、档案研究 |
| 原始文献与译本 | 多依据英译/中译与二手史学 | 个别术语、年份、立场可能有转述误差 | 原始德文/法文/俄文/英文文献 |
| 图像与档案 | 插图是示意图，不是历史照片 | 不能作为史料使用 | 档案馆、图像史、实验原始记录 |
| 跨流派的可通约性 | 用“取舍”框架强行比较 | 有些分歧不可通约，本书可能抹平 | 科学哲学、范式理论、比较研究 |

## 四条性质边界

1. **它是解释，不是判决。**“它让出了什么”是作者的解释，不是史学定论。
2. **它是主线，不是全景。**25 章必然漏掉很多流派与人物。
3. **它是中文写作，不是翻译。**术语、例子、语气为中文读者而写。
4. **它会过时。**“当前”指 2026 年 10 月；五年后部分段落需要重写。

## 三种“如果发生，本书需要改写”的情况

- 出现一个统一的心理学理论，能同时解释深度、可观察、可传递。
- 复现危机被证明是夸大的（大规模复现显示高复现率）。
- 非西方心理学传统被系统地翻译、检验、整合。
