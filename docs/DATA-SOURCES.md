## 引用原则

- 能查证的年份、人物、著作，标 A；稳定的公开估计，标 B；思辨/解释，标 C。
- 有争议的实验（小艾伯特、斯坦福监狱、米尔格拉姆），正文同时给原始报告与后来的方法学批评，不把任何一方写成定论。
- 对人物的临床推测，一律标 C，并说明它只是解释，不是诊断。
- 不伪造数据；不把 C 级材料写成 A 级。
